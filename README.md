# learning_dart
Dart tutorial:  Begin your Dart learning journey by building an interactive CLI app. From: https://dart.dev/learn/tutorial

## System Requirements

- Dart SDK installed (latest stable recommended)
- A compatible operating system such as Windows, macOS, or Linux
- A terminal/command prompt to run the CLI
- Optional: an IDE or text editor for Dart development


A sample command-line application with an entrypoint in `bin/`, library code
in `lib/`, and example unit test in `test/`.
